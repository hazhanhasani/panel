# BluePanel

BluePanel — самостоятельная панель управления Xray, пользователями, подписками, узлами, лимитами трафика и статистикой.

## Быстрая установка

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/hazhanhasani/panel/main/install.sh)" @ install
```

Управление:

```bash
bluepanel status
bluepanel logs
bluepanel update
bluepanel restart
```

Обновления загружаются только из `https://github.com/hazhanhasani/panel`. Данные хранятся в `/var/lib/bluepanel`.

Лицензия и обязательные уведомления исходного открытого проекта сохраняются в соответствии с условиями лицензии.

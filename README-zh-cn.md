# BluePanel

BluePanel 是一个独立的 Xray 管理面板，用于用户、订阅、节点、流量限制和统计管理。

## 快速安装

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/hazhanhasani/panel/main/install.sh)" @ install
```

管理命令：

```bash
bluepanel status
bluepanel logs
bluepanel update
bluepanel restart
```

BluePanel 更新只从 `https://github.com/hazhanhasani/panel` 获取。持久数据保存在 `/var/lib/bluepanel`。

根据原开源许可证要求，许可证文件和必要的法律声明会继续保留。
